A momentum / lifecycle forecaster for pump.fun coins: it fits age-banded drift and volatility from the snapshot history, Monte-Carlo simulates each candidate coin to every answer read, and spreads honest probabilities across the churn — leaving room for the coins born after the cut.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
